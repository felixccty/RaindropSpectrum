# 注意事项与已知限制

## 1. 源码编码

- `.cpp/.h` 为 **GBK** 编码，含中文注释与界面字符串（部分源文件使用 `#pragma execution_character_set("utf-8")` 指定执行字符集）；
- `.ui/.sln/.vcxproj/.filters` 为 **UTF-8**；
- 使用编辑器修改时请保持原编码，整体转 UTF-8 会导致中文注释与字符串乱码、编译告警或界面文字异常。

## 2. 固定路径常量

代码中存在若干**运行期固定路径**，部署时需留意：

| 路径 | 用途 | 位置 |
|------|------|------|
| `C:\rain_data` | 数据目录（`folderPath` / `folderPath_c`） | `raindrop_spectrum.cpp` 顶部静态变量 |
| `C:\rain_data\Rain_record%G-%m-%d.csv` | 当日雨滴记录文件 | 构造函数与 `timeSlot()` 中 `strftime` 拼接 |

这些是程序约定，非本机绝对路径；如需改到其它盘符，请修改源码常量后重新编译。程序以 `"a"` 追加方式写文件，首次运行会在构造函数中写入表头。

## 3. 第三方硬件与库依赖

- 本项目**不含雨滴识别的物理标定算法**，只做阈值穿越检测与原始量值记录；要得到直径/速度物理意义需用户自行标定（见 [数据来源说明](../README.md#数据来源说明)）。
- 采集功能依赖 USB9825 采集卡及其闭源 SDK（`USB9825.lib` + 驱动）；无硬件时程序可启动但无法采集数据。
- `QCustomPlot` 源码（`.vcxproj` 中引用的 `qcustomplot.cpp/.h`）未随发布包提供，需自行准备，否则链接失败。

## 4. 运行库与部署

发布包仅含源码与资源，不含 Qt 运行库与 SDK 二进制。请用 `windeployqt` 收集 Qt 运行库，并随附采集卡 SDK 的运行时 DLL 与驱动，避免目标机器启动失败或连接设备失败。

## 5. 已知限制

- `.qrc` 当前为空，界面不依赖内嵌资源；
- 采集参数为源码固定配置，运行时界面上的触发频率/触发长度等控件并未接入 `USB9825_PARA_INIT`，仅阈值（`spinBox_3`）实际生效；
- `timer1` 间隔设为 0.1 ms，配合 `Sleep(1)` 的忙等与 `qApp->processEvents()` 保持界面响应，高负载下时间精度有限；
- `timeSlot_ra()` 按系统分钟翻转聚合，跨分钟边界的雨滴计入翻转后的新分钟；
- 谱图网格单元以 `duration`（`clock()` 计时差值）为纵轴索引，与物理速度量纲之间需要用户自行建立换算关系；
- `spY1->setUseOpenGL()` 依赖运行环境具备 OpenGL 支持。
